# «Оператор спуска» (рабочее название) — версия 0.1 для Android

Голосовой навигатор спуска: сравнивает движение с записанным профилем и подаёт команды
«Лево 30», «Право 45», «Снизь скорость», «Тормози», «Левый край» и др. Подходит для
испытаний на велосипеде: летняя трассировка записывает геометрию трассы.

## Сборка APK

**Вариант А — Android Studio (Windows).**
1. Установить Android Studio (бесплатно, developer.android.com/studio).
2. File → Open → папка `spusk`. Дождаться синхронизации Gradle (нужен интернет).
3. Build → Build App Bundle(s) / APK(s) → Build APK(s). Файл появится в
   `app/build/outputs/apk/debug/app-debug.apk`.
4. Либо подключить телефон по USB (включена «Отладка по USB») и нажать Run ▶.

**Вариант Б — без установки, через GitHub.**
1. Создать репозиторий на GitHub и загрузить в него содержимое папки (вместе со скрытой `.github`).
2. Вкладка Actions → «Сборка APK» запускается сама; через 4–6 минут в разделе Artifacts
   появится архив `spusk-operator-apk` с файлом `app-debug.apk`.

**Установка на телефон.** Скопировать APK на телефон, открыть, разрешить установку из этого
источника. Android 8.0 и новее. При первом запуске разрешить точную геолокацию и уведомления.
Для голоса нужен русский пакет синтеза речи (Настройки → Специальные возможности →
Синтез речи).

## Экран

* **Уровень лыжника** — «Новичок», «Опытный», «Мастер», «Свой». Долгое нажатие на «Свой» —
  поставить своё фото (галерея или камера). Пороги уровней — таблица 2 ТЗ.
* **Профиль спуска** — выбор записанного профиля.
* **Режимы**: Навигация, Стоп, Симуляция (проезд по профилю без GPS, для проверки дома),
  Трассировка, Левый край, Правый край, Фото ориентира, Ошибки от профиля.
* **Обмен**: «Отправить» (системное меню: Bluetooth, Quick Share, мессенджер), «Принять файл».
  Файл `.descent` проверяется по SHA-256; повреждённый не принимается.
* **Пульт оператора** — 18 кнопок команд и «Сказать команду голосом».

## Порядок велосипедного эксперимента

1. **Трассировка**: проехать спуск спокойно по оптимальной линии → «Стоп» → название,
   «велосипед», «лето» → Сохранить.
2. **Левый край / Правый край**: проехать (или пройти) вдоль каждой бровки → «Стоп».
   Направление записи края значения не имеет.
3. На опасных местах — **Фото ориентира** (можно во время трассировки).
4. Выбрать уровень → **Навигация** → телефон в карман или на руль, один наушник.
5. После спуска — **Стоп**: откроется разбор ошибок и показатель Q; «Отправить журнал» даёт CSV
   (время, координаты, точность, скорость, e, λ, ε, класс ошибки, прозвучавшая команда) —
   это исходные данные для проверки гипотез Г1–Г5 из ТЗ.

Безопасность: на экран во время езды не смотреть; громкость такая, чтобы слышать окружающих.

## Устройство кода

| Файл | Назначение |
|---|---|
| `Geo.kt` | формулы (1), (2), (4), локальная проекция, ломаная, Дуглас — Пекер |
| `Navigator.kt` | привязка к линии, формулы (3), (5)–(11), правила команд, классы ошибок |
| `Commands.kt` | библиотека команд, приоритеты, вибропаттерны, разбор голосовой фразы |
| `Model.kt` | профиль, уровни (Новичок/Опытный/Мастер/Свой) |
| `ProfileStore.kt` | JSON-формат профиля (таблица 3 ТЗ), контрольная сумма |
| `LocationService.kt` | GPS 1 Гц в службе переднего плана (работает при погашенном экране) |
| `Speaker.kt` | синтез речи с прерыванием по приоритету, вибрация |
| `Hub.kt` | режимы, запись, симуляция |
| `MainActivity.kt`, `TrackView.kt` | экран и схема спуска |

## Пока не сделано

QR-обмен (нужна библиотека сканера), подложка карты OSM, передача фото ориентиров вместе
с профилем, настройка порогов «Своего» профиля на экране.
